# retail-sales-inventory-analysis

**My Individual academic project for data analysis report on retail sales and inventory**

---

### Summary
A comprehensive individual Python project analyzing over 125,000 sales records and 284,000 inventory records to uncover product performance trends, sales channel patterns, and inventory optimization strategies.

---

### Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook

---

### Methodology & Workflow
* **Data Cleaning & Inspection:** Audited datasets for missing values, verified data types, and validated overall data quality prior to analysis.
* **Exploratory Data Analysis (EDA):** Segmented sales and inventory metrics across product categories, stock statuses, and sales channels to highlight behavioral patterns.
* **Business Insights & Recommendations:** Translated technical outputs into strategic guidance covering seasonal demand forecasting, returns management, markdown optimization, and inventory planning.

---

The full dataset containing over 125,000 sales records and 284,000 inventory records is too large to host directly on GitHub and the complete data can be sourced from [Google Drive](https://drive.google.com/drive/folders/1FPi99JXOrN5O6WUjUaLalEWPDvEcS0OI?usp=drive_link).
